# Capturas requeridas

Guarda en esta carpeta tres capturas del dashboard con estos nombres:

- `escritorio.png`: navegador con ancho aproximado de 1440 px.
- `tablet.png`: navegador con ancho aproximado de 768 px.
- `movil.png`: navegador con ancho aproximado de 390 px.

En Google Chrome puedes obtenerlas así:

1. Abre `index.html`.
2. Presiona `F12` y luego `Ctrl + Shift + M`.
3. Escribe el ancho requerido en la barra superior.
4. Abre el menú de tres puntos del modo dispositivo y selecciona **Capture full size screenshot**.
5. Renombra la imagen y guárdala en esta carpeta.
